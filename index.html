01

remediation-report

review findings → remediation plan → HTML

Available

What it does

Turns the findings of a security review, code review, audit or technical-debt pass into one self-contained HTML file with a remediation plan ordered by urgency.

  • Prioritizes findings into executable phases with files, steps, effort and verifiable criteria.
  • Renders from schema-validated JSON and checks the page in a headless browser before publishing.
  • After the fixes land, it updates the same file and recomputes resolved findings, applied commits and totals.

npx skills add AlexAdiaconitei/skills --skill remediation-report

02

planning-dossier

decisions → immutable rounds → implementation handoff

Available

What it does

Builds a planning record backed by evidence from the repository, with the decisions you can make now, the open threads and an implementation handoff.

  • Shows only decisions whose dependencies are resolved, while tracking blocked and deferred threads.
  • Tests each round in a headless browser before publishing it. Published rounds never change, the index tracks the current state, and answers autosave in the browser.
  • Exports compact Markdown continuation capsules and a final handoff without changing product code.
