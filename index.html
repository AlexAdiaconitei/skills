remediation-report

review findings → remediation plan → HTML

Available

What it does

Turns security reviews, code reviews, audits, and technical-debt findings into a self-contained HTML remediation plan, ordered by urgency and ready to share.

  • Prioritizes findings and groups them into executable phases.
  • Includes files, steps, effort estimates, and verifiable criteria.
  • Delivers an editorial dossier as a single HTML file.
View skill files

Installation

Install this skill in the current project with the skills CLI:

npx skills add AlexAdiaconitei/skills --skill remediation-report
Global
npx skills add AlexAdiaconitei/skills --skill remediation-report -g
Manual
Copy skills/remediation-report/ to .claude/skills/.

Trigger it by asking

“Prepare an HTML remediation plan from these findings.”
