This version replaces the original visual design with the Editorial Dossier system from this repository's `DESIGN.md`. It adds planning rounds that never change once published, an index that does, form controls for decisions, local autosave, short Markdown continuation capsules and a deterministic renderer.

Files were changed for this skill. Generated dossiers include their own planning content and are not copies of the upstream examples.
